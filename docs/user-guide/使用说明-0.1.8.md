乳腺癌药物先导化合物筛选优化平台 v0.1.8
界面与报告使用补充说明

软件包含六个主模块，采用蓝色主题。训练模型仍为 v0.1.0-71dee9e63f35-s42，原四模型、融合权重、数据划分、阈值默认值和指标未改动。

一、数据导入与清洗
“下载 CSV 模板”保存仅含表头的空白模板，不附带虚构测量值。请填写真实 SMILES、IC50、units 和精确关系 relation（=）；单位支持 M、mM、uM/µM、nM、pM。来源与许可在导入弹窗填写。支持字段映射和 UTF-8 / GB18030 编码。
“获取 ChEMBL 数据”优先复用本地快照；“更新数据快照”先备份旧原始快照，再获取并清洗新记录，替换待训练数据。已加载模型保留。数据操作开始时，旧分子报告失效。
已选文件、映射和来源可展开查看。错误会定位字段或来源，修正时保留输入；清洗步骤显示实际进行状态。网络或清洗失败后可重试；本次数据未就绪时禁止训练，上次清洗文件和已加载模型保留。

二、模型训练
左侧为本次待训练数据及下一次训练设置，右侧为当前已加载模型的历史数据划分、完成时间和指标。修改左侧随机种子不会重新计算历史指标。“重置设置”只恢复下一次训练种子42并收起方法说明。
固定训练 ANN、RF、XGBoost、LR 四个模型，采用只读列表。未准备至少60个有效化合物且 pIC50 标准差不足0.1时不能开始训练；结构组及各拆分集合是否满足要求仍会在实际训练前校验。
训练运行时禁用重复操作；失败后保留原已加载模型。负 R² 如实展示，强调文案仅指当前记录下的单模型比较。底栏的报告和融合入口固定可见。

三、融合优化
GA为遗传算法，SA为模拟退火，TS为禁忌搜索。表格用于比较三方案，横条用于查看选定权重。
显示的权重百分比、RMSE会四舍五入。悬浮验证 RMSE 单元格可查看原始精度和用于选择的 MSE；运行详情可复制完整精度。代码按未四舍五入的验证集 MSE 选择，完全相等时按 GA、SA、TS 顺序选择。独立测试不参与调权或方案选择。
模型融合权重与三级筛选阶段权重是不同参数。

四、分子预测与结果有效性
无输入或无模型时不能预测。载入示例只填入结构，点击“预测活性”或按 Enter 后才计算结果。预测在后台运行，显示进行状态并防止重复提交；错误在输入框下显示，保留原输入，修正后重试。
修改 SMILES、加载模型或调整筛选参数后，旧报告显示“已失效，请重新预测”，禁止导出。重新预测后，结构图、四模型数值、融合结果、阶段状态和导出文件一起更新。这里的“重新预测”是用已有模型重新推理，不是重新训练。
底部“导出结果”菜单保存当前有效结果的完整 HTML、CSV 或 JSON；“查看报告”仅在有效预测后启用。需要选择栏目时到“结果与导出”。

五、三级漏斗
没有预测时显示“未开始”，没有外部证据时显示“缺少证据 / 未评估”，均不等同于不通过。状态同时使用文字和符号。已知判定条件提前显示；完整综合评分在缺失阶段时保持未完成。
导入阶段证据前需完成当前分子的有效预测。证据要有相同 canonical_smiles 和可追溯 evidence 来源。ADMET需完整5项输入；结构/理化需67项不同约束定义和对应布尔判定。
导入或清除阶段证据后，旧报告同样失效，需要重新预测。“清除阶段证据”移除当前导入证据并退出演示，不删除模型或已有导出文件。演示输入始终标注，不作为科研结论。高级参数默认折叠。调整门槛、阶段权重或奖惩后，请重新预测以更新报告。
pIC50低于6.0为硬性淘汰，不能由其他阶段加分放行。RDKit描述符不代表完整67项结构评估。

六、结果与导出
分子筛选与模型训练分别管理。无有效分子报告时显示待生成内容，并提示“完成有效预测后可导出”。训练报告的运行 ID、SHA256 与原始 JSON 在“运行详情”中，可复制。
格式说明随报告和格式变化：
HTML用于阅读和打印。分子报告所选分子图内嵌，断网可读；训练报告包含所选指标、划分、权重和运行信息。
CSV用于表格分析。分子报告每个分子一行；训练报告选择模型指标时每个模型/融合方案一行，否则为一行所选摘要元数据。训练CSV追溯列只包含摘要字段，避免巨型JSON超过Excel单元格长度；完整优化历史和模型参数请导出JSON或模型及运行记录。
JSON用于结构化数据与运行记录；全选时保留完整原始记录。CSV追溯列和部分JSON同样按勾选项输出。
模型版本、数据标识、结论和科学边界作为最低追溯信息保留。取消一个栏目不一定会移除其他栏目所必需的相同事实，例如筛选原因仍需注明活性门槛。
“导出模型及运行记录”另存文件夹，包括4个模型、完整训练报告、指标CSV、清洗摘要和可用运行日志，不受栏目勾选影响。
成功后记录时间、类型、文件名、格式和大小；可打开文件和所在文件夹。失败会说明原因并保留有效结果供重试，不新增成功历史。文件已移动或删除时会提示。最多保留200条历史，页面展示最近20条。

七、界面与保存
常用操作固定底栏，主页面切换回到顶部。窗口最低880×460逻辑像素；内容超出时滚动查看，长SMILES可横向查看和复制，长标识可在详情查看完整值。
中文采用微软雅黑 UI/微软雅黑回退，数字使用 Segoe UI 的等宽数字特性。蓝色用于主要操作和少量重点，正文为深灰。
安装版工作目录默认为 %LOCALAPPDATA%\ERLeadPlatform。基础PDF/Word保留旧版背景；当前交互以上述补充说明为准。显示效果随显示器缩放和系统字体设置变化。
