# 三级漏斗和奖惩规则

以下为当前范围内可测试的实现规则，不增加ADMET或67输出模型训练。软件默认仅使用真实活性回归结果，后两阶段无有效输入时显示未评估、综合分为空。

## 两组权重

四模型融合权重由GA/SA/TS在验证集优化，非负且总和为1，用于生成一个pIC50。阶段权重默认0.40/0.35/0.25，分别用于活性、ADMET、结构评分，可配置且非负、和为1。

## 阶段判定

| 阶段 | 输入和门槛 | 输出及流转 |
|---|---|---|
| 1 活性 | 真实模型pIC50；默认门槛6.0，可在6.0–12.0调严 | 低于门槛硬淘汰；否则通过。S1=min(pIC50/8,1)，失败时为0 |
| 2 ADMET | logS默认[-4,0]；F≥30%；PPB≤95%；肝毒性和CYP3A4高抑制风险均为False | 两项风险标志任一True时硬淘汰、S2=0；其余不达标时需复核；全符合则通过。S2=通过项数/5 |
| 3 结构/理化 | 外部提供完整67项布尔判定及定义，或明确标注的流程演示输入 | S3=通过项数/67；67项全符合为通过，其余需复核。未提供完整真实输入时未评估 |

ADMET数值门槛可调；风险标志的硬拦截保持有效。缺测、需复核、淘汰均不会自动放行到下一阶段；已有后续输入可作为辅助信息展示，流转栏标记未放行。

## 完整评分和奖励惩罚

仅三个阶段都有有效输入时：

```
base = w_stage1*S1 + w_stage2*S2 + w_stage3*S3
adjusted = clip(base + reward*base - penalty*(1-base), 0, 1)
```

reward、penalty可在0–1调整，默认均为0，保留原始加权公式。每次导出记录基础分、调节后分数、参数和输入来源。规则是参数化评分，不是强化学习或分子生成。

优先级：硬淘汰 > 缺测 > 需复核 > 综合分等级。只有三阶段真实输入完整且阶段均通过，才根据≥0.8、≥0.6、≥0.4和<0.4显示对应候选等级；任何硬淘汰都不能被奖惩或高总分覆盖。

演示输入使用固定、可编辑的样例值，不参与训练；所有结论和综合分标记“流程演示”。67项演示计数仅代表占位布尔流程，不声称具备67项完整科学定义。默认关闭演示；更换分子会清除旧分子的外部阶段证据，防止套用其他分子的测量结果。

## 可追溯性

参数保存时保留当前配置和带时间的历史快照。预测JSON/CSV包含SMILES、模型版本、数据哈希、四模型预测、融合权重、阶段输入/状态/流转、奖惩参数、演示标志和外部证据。模型内已有的训练数据审计绑定模型版本导出，不使用后来导入的数据替换来源。
